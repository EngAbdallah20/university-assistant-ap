# AKI — New local portfolio

A fresh bilingual portfolio concept with a warm editorial look, cobalt blue accents, and a lime highlight. Built with plain HTML, CSS, and JavaScript.

## Preview

Open `index.html` in a browser. The portrait and monogram are reused from `../aki-portfolio/assets/`.

## Files

- `index.html` — page content and semantic structure.
- `styles.css` — responsive visual system, project illustrations, and motion.
- `script.js` — language switcher, mobile navigation, scroll progress, and reveal effects.

Project images are interface illustrations, not screenshots of finished products. Project status and planned technologies are described transparently. The profile does not invent employment, certificates, awards, or results.
