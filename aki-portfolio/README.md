# AKI — Personal portfolio

Bilingual responsive portfolio for Abdullah Khaled Ibrahim. Built with plain HTML, CSS, and JavaScript; no build step required.

Open `index.html` in a browser to preview. `script.js` handles the language switch, mobile navigation, scroll progress, active navigation, and scroll reveals. The CSS respects reduced-motion preferences.

## Files

- `index.html` — portfolio content and page structure
- `styles.css` — responsive theme, animated project illustrations, learning-roadmap cards
- `script.js` — page interactions
- `assets/aki-logo.svg` — AKI monogram
- `assets/portrait.jpg` — optimized copy of the supplied portrait

The project illustrations are original UI mockups, not screenshots of finished products. Project and technology statuses are labelled as concepts or planned work.
